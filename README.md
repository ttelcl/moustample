# moustample

A tool for text templating. The name is derived from a contraction of _moustache_ and _template_,
and shaking up the letters a bit to get a seemingly unique name. "_moustache_" here refers to the
nickname for the '{' character, which is heavily used in the moustample template language.

While different, the language design was influenced by
[liquid](https://shopify.github.io/liquid/) and [scriban](https://github.com/scriban/scriban).
